- **Excel**：标题、筛选条件、导出人与时间；表头冻结、自动筛选；金额/数字/日期为真实格式；合计行使用 `SUBTOTAL`，在 Excel 里再次筛选时合计自动更新。
- **PDF**：A4 横向，含筛选条件、条数、合计行，中文正常显示。
- 导出内容 = 当前页面筛选后的行（服务端 `POST /api/v1/export/table` 只负责渲染，不额外查询数据）；单次最多 20,000 行。
- **打包下载**：每张单据一个 PDF，打成一个 ZIP（工资条按工号_姓名命名，发票按发票号_客户命名）；单次最多 500 张。
