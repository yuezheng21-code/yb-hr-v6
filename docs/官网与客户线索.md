# 官网 · 客户线索 · 在线求职

访问根地址 `/`（未登录）即为公司官网；已登录用户访问 `/site` 查看官网。右上角「登录」进入系统，登录页左上角可返回官网。

## 页面结构（德语默认，可切换 English / 中文）
- **Leistungen 服务**：Amazon/TEMU 仓内作业、装卸柜、模块运营（Werkvertrag）、人员派遣（AÜG 合作方）、驻场管理、供应商与容量管理
- **Über uns 关于我们**：内容取自《IWO 仓储运营整合白皮书》——强管理/强数据/强供应链/持续改善、需求→工单→资源→证据→结算→决策闭环、90 天试点、AÜG 与 GDPR 合规说明。白皮书中的价格、财务测算等示例数字未放到官网。
- **Für Unternehmen 企业合作**：询价表单 → 「客户线索」
- **Karriere 加入我们**：在招岗位（来自「派遣需求」中状态为 open / recruiting 的需求，只公开岗位、地点、人数、开始日期、班次）+ 求职表单 → 「人才储备池」

公司名称、地址、电话、邮箱在 **系统设置 → 公司** 中维护（`company_email`、`company_phone` 为新增项）。

## 业务流
1. 客户提交需求 → **客户线索**（admin / HR / 运营经理可跟进，财务只读）：状态 新线索 → 已联系 → 报价中 → 已报价 → 成交/流失/无效，记录负责人与内部跟进记录。
2. 「生成报价单」→ 按需求自动创建报价单草稿（客户、联系人、预计人数、服务说明；含装卸柜/项目/驻场的需求默认「项目承包」，否则「纯派遣」），之后在 **工程报价** 中测算成本、定价、审批、导出。
3. 求职者投递 → 人才池（渠道「官网投递」，附简历）；同名同电话重复投递只追加记录。HR 在人才池「转为员工 · 建档」时，简历自动归入员工档案（求职材料）。

## 防滥用与隐私
- 必须勾选隐私同意；隐藏蜜罐字段拦截机器人；每个 IP 每 10 分钟最多提交 5 次。
- 公开接口只返回公司联系方式和岗位概要，不暴露客户、价格或员工数据。
- ⚠ 德国网站需 **Impressum（法律声明）与 Datenschutzerklärung（隐私政策）**，请提供公司注册信息后补充页面。

## API
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/public/info` | 公开：公司联系方式、服务、在招岗位 |
| POST | `/api/v1/public/inquiry` | 公开：企业询价 |
| POST | `/api/v1/public/apply` | 公开：求职（multipart，`cv` 可选） |
| GET / PUT | `/api/v1/leads`、`/api/v1/leads/{id}` | 线索列表 / 跟进 |
| POST | `/api/v1/leads/{id}/quote` | 生成报价单草稿 |
| GET | `/api/v1/leads/talent/{id}/cv` | 查看候选人简历 |
