# 财务中心：工资条 · 供应商结算单 · 甲方账单 · DATEV / 税务

入口：侧边栏「财务中心」（admin / 财务 fin 全部；HR：工资条、供应商结算、DATEV 工资；运营经理：只读账单与客户；供应商账号：只看自己的结算单）。工人：「我的工资条」。

## 准备（系统设置）
- **开票信息（§ 14 UStG 必备）**：公司名称、地址（含邮编城市）、Steuernummer 或 USt-IdNr.、商业登记、银行 / IBAN / BIC、邮箱、电话；增值税率（默认 19%）、默认付款期限。
- **DATEV**：Beraternummer、Mandantennummer、SKR03/04、财年开始月、收入/§13b/外包费用科目、BU-Schlüssel、债务人/债权人编号起始；LODAS Lohnart（工时 / 计件卸柜 / 奖金 / 扣款）。**这些须与税务师的 Mandant 设置一致，首次使用请先做测试导入。**
- 员工档案 → 个人信息：填写 **DATEV 人员编号**（LODAS 导出用）、地址、税号、社保号、IBAN。

## 1. 工资条（Entgeltabrechnung）
1. 工时记录审批入账（booked）后，选择月份 →「从已入账工时生成」：按员工汇总 Grundlohn（按仓库/时薪）、计件、卸柜计件、KPI 奖金、津贴，工时单扣款自动列为其他扣款。
2. **税与社保**（Lohnsteuer、Soli、KiSt、KV/RV/AV/PV 员工部分）**系统不自行计算**：以工资核算软件（DATEV 等）的结果为准，在明细中录入，或导入 CSV：
   ```
   emp_no;lst;soli;kist;kv;rv;av;pv
   YB-2026-001;80,50;0;0;95,20;108,00;15,60;20,00
   ```
   （也可用 `pnr` = DATEV 人员编号；德文列名 Lohnsteuer/Krankenversicherung… 亦可识别）。未录入时工资条按税前金额出具并注明。
3. 可添加预支（Vorschuss）等其他扣款与备注 → 签发：锁定，PDF 存入员工档案「薪资」类，工人在「我的工资条」查看/下载。管理员可撤回签发。

## 2. 供应商结算单（Leistungsabrechnung）
按已入账的供应商人员工时生成，每家供应商一张：人员、天数、工时、金额、净额 + 增值税。PDF 给供应商据此开票，另有逐日工时 CSV（Leistungsnachweis）。供应商账号登录可下载自己的。发票号/付款在「月度结算」登记后会进入 DATEV 应付导出。

## 3. 甲方账单（Rechnung）
1. 「客户」：添加甲方开票抬头（地址、USt-IdNr.、付款期、§13b、XRechnung 参考号 / Leitweg-ID、DATEV 债务人科目）并**关联仓库**。
2. 「新建账单」：选客户与服务期间，勾选计费来源：
   - 工时（仓库已审批）× 仓库客户时薪（仓库价格配置）
   - 装卸柜（已审批）× 柜型单价（或卸柜记录上的客户金额）
   - 计件作业（已确认）× 作业类型客户单价 —— 注意不要与工时重复计费
3. 草稿可逐行修改/增删 → 预览 PDF → **开具**：分配连续发票号 `RE-年份-00001`、计算到期日、PDF 存档、锁定。
4. 开具后：下载 PDF / **XRechnung（UBL 2.1，EN 16931）** 电子发票 XML、登记收款；错误发票只能**作废 → 自动生成红字发票（Stornorechnung，金额取负并引用原发票号）**，不删除不改号。
5. 列表显示待收款、逾期金额。

## 4. DATEV / 税务
- **DATEV Buchungsstapel（EXTF）**：本月开具的账单（应收：债务人 ↔ 收入科目；§13b 用反向征收科目）+ 已开票供应商结算（应付：债权人 ↔ 外包费用科目 + BU 9）。交税务师导入 DATEV Rechnungswesen。
- **DATEV LODAS ASCII**：每位员工本月工时、计件/卸柜金额、奖金、扣款（按配置的 Lohnart）。无 DATEV 人员编号的员工会被跳过并在页面提示。另有**通用 CSV**（Lohn und Gehalt / 其他工资软件）。
- **UStVA 预估**：Kz 81（19% 应税收入及税额）、Kz 60（§13b）、Kz 66（供应商结算进项税）、应缴/退税。仅含本系统数据，正式申报请以税务师为准。
- 直接向税务局（ELSTER）报送需要 ERiC 证书与认证软件，通常由税务师经 DATEV 完成；本系统提供上述导出作为对接方式。

## 说明
- PDF 内嵌文泉驿正黑子集字体，中文姓名在任何阅读器中可正确显示。
- 金额按商业规则四舍五入（红字发票金额与原发票完全相反）。
- 已签发工资条、已开具发票均存档于数据库，满足留档要求（GoBD：不可修改，只能作废冲销）。
