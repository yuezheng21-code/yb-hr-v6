# 人事档案（Personalakte）· 文书模板 · SOP

## 全流程
人才库候选人 →「转为员工 · 建档」→ 员工档案（花名册点姓名 / 「档案」）→ 签订合同 → 合同修订 / 调薪 / 绩效评估 / 请假 / Abmahnung / 备注 → 离职。
每个动作都写入**时间线**，并可同时上传附件（签字扫描件、AU 病假证明等）或直接用模板生成正式文书，文件全部归入该员工档案。

| 动作 | 记录内容 | 自动处理 |
|---|---|---|
| 签订合同 | 类型（befristet / unbefristet / Minijob / Werkstudent / Aushilfe）、期限、试用期、工时、时薪、年假、解约期 | 定期合同必须有结束日；时薪低于 P1 标准 90% 拒绝；默认 6 个月试用期；新合同生效时旧合同结束，并同步员工岗位/仓库/时薪 |
| 合同修订 | 修订摘要 + 变更项 | 生成新版本 `原编号-N1…`，旧版标记「已修订」 |
| 调薪 | 新时薪、生效日、原因 | 立即更新员工时薪与生效合同（当前不支持未来日期自动生效） |
| 绩效评估 | 期间、1–5 分、评价/优点/改进/目标 | 自动带入该期间作业绩效（效率、质量、等级） |
| 请假 | 类型、起止、状态 | 按周一至周五计算工作日；时间重叠拒绝；病假 > 3 天标记需 AU 证明；统计年假已用/应有 |
| Abmahnung | 日期、事由、经过 | 编号累计，可直接生成书面警告 |
| 离职 | 类型、通知日、最后工作日 | 员工改为离职、合同结束，可停用登录 |

档案页顶部的**到期提醒**（花名册页）：合同到期、试用期结束、证件/工作许可到期（上传文件时填写「有效期至」）。

## 文书模板
「文书模板」页（admin / HR）。内置：定期劳动合同、涨薪补充协议、Abmahnung、普通解雇通知、工作证明。
- `{{employee.name}}`、`{{contract.hourly_rate}}`、`{{company.name}}` 等自动从档案 / 合同 / 系统设置填充（公司地址、法定代表人在「系统设置」中填写）；
- `{{key|标签}}` 为 HR 生成时手填字段，标签含 “optional / 可选” 的可留空；
- 生成：预览 → 补填 → 「生成并存入档案」（DOCX，记录模板版本）或「下载 Word」。
- 修改正文版本号自动 +1。

> ⚠ 内置模板为德国劳动法通用示例（Muster），不构成法律意见。作为 Personaldienstleister 若适用 AÜG 或 iGZ/BAP 集体协议，条款需调整；解雇须书面原件亲笔签名（§ 623 BGB）。正式使用前请由劳动法律师审核。

## SOP 学习资料
所有内部角色可查看；admin / HR / 运营经理可上传（PDF、图片、Office、短视频，≤ 15 MB）或直接写正文，可标记「必学」、指定仓库与语言。
员工阅读后点「我已阅读并理解」，按版本记录；修改版本号后需要重新确认。编辑者可查看每份资料的学习名单。

## 存储与权限
- 文件存入 PostgreSQL（`file_blobs`），Railway 无持久磁盘也不会因重新部署丢失；单文件 15 MB，校验扩展名与文件头。
- 档案文件只做软删除（保留审计）。
- 人事档案与模板仅 admin / HR；甲方账号无法访问任何人事接口。
