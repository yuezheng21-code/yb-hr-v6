# Fonts

`wqy-zenhei-gb2312.ttf` — subset of **WenQuanYi Zen Hei** (文泉驿正黑) limited to the GB2312 character set,
Latin-1 and common punctuation. Used to embed Chinese characters (e.g. employee names) in generated PDFs
(payslips, statements, invoices).
